## 🚧 Current Status

VamoraOS is currently in active development.

The repository now contains the Live-Build (`lb`) configuration used to build the operating system. Additional source code, applications, and documentation will be added as development progresses.

## 📂 Repository Contents

- 🛠️ Live-Build configuration
- 📦 Build scripts (coming soon)
- ⚙️ Configuration files
- 📚 Documentation (coming soon)
- 💻 Desktop source code (coming soon)
